# 15 билетов для практикума по Linux (1,5 часа каждый)


---

## Билет 1. «Первый сервер»
**Сценарий:** развернуть VM с нуля и зафиксировать базовую среду.
- Развернуть ВМ через гипервизор, показать настройки сети и снять снимок состояния.
- Установить Linux Server, первичная настройка (hostname, timezone, обновления).
- Изучить FHS: найти `/etc`, `/var`, `/home`, `/usr`, `/proc`.
- Создать пользователя и группу, выдать sudo.
- Настроить права на общий каталог `/srv/shared` (chmod, chown, umask).
- Посмотреть процессы (`ps`, `top`), отправить сигнал `SIGTERM`.
- Написать Bash-скрипт с переменными и аргументами.
- Использовать перенаправления и конвейер (`grep`, `awk`, `sort`).
- Добавить цикл и условие, обработать код завершения.
- **Отчёт:** вывод команд + скрипт диагностики, сохранённый в `/root/reports/`.

## Билет 2. «Виртуализация и снимки»
- Создать 2 ВМ, настроить виртуальную сеть (bridge/host-only), сделать снимок.
- Установить Linux Server на первую ВМ, вторую использовать как «эталон».
- Изучить FHS на живой системе, сравнить с документацией.
- Работа с файлами: маски, поиск (`find`, `locate`), справка (`man`, `--help`).
- Создать группу `devops`, пользователя, настроить sudo.
- Права: chmod 750, chown, umask 027, безопасный общий каталог.
- Процессы: запустить `sleep 1000`, найти PID, отправить `SIGKILL`.
- Bash-скрипт: переменные, аргументы, `$?`.
- Потоки: `>`, `>>`, `2>`, `|`.
- Условие + цикл + функция + `set -e`.
- **Отчёт:** сравнение снимков до и после, скрипт в `/root/reports/`.

## Билет 3. «Файловая система и FHS»
- Развернуть ВМ, показать гипервизор, образ диска, сетевые адаптеры, снимок.
- Установить Linux Server, разметить диск (/, /home, /var).
- Пройтись по FHS: `/bin`, `/sbin`, `/lib`, `/mnt`, `/opt`, `/tmp`.
- Файлы: создать, копировать, переместить, маски, поиск по имени и содержимому.
- Справочная система: `man`, `info`, `apropos`.
- Пользователи и группы: `useradd`, `groupadd`, `usermod`, sudoers.
- Права: chmod символьный и числовой, chown, umask, sticky bit.
- Процессы: `ps aux`, `pgrep`, `kill -SIGSTOP/-CONT`.
- Bash: скрипт с аргументами и кодами завершения.
- Перенаправления и конвейеры с `cut`, `tr`, `wc`.
- Цикл `for` по файлам, функция логирования, `trap`.
- **Отчёт:** дерево каталогов FHS + скрипт в `/root/reports/`.

## Билет 4. «Пользователи и права»
- ВМ: настройки гипервизора, сеть NAT, снимок перед экспериментами.
- Установка Linux Server, первичная настройка.
- FHS: где хранятся конфиги пользователей (`/etc/passwd`, `/etc/shadow`, `/etc/group`).
- Файлы и каталоги: создание, маски, `find`, `man`.
- Создать 3 пользователей, 2 группы, настроить sudo без пароля для одной команды.
- Права: chmod, chown, umask, общий каталог с SGID.
- Процессы: запустить от разных пользователей, посмотреть владельца (`ps -o user`).
- Bash: переменные, `$1..$9`, `$#`, `$?`.
- Потоки: логирование в файл и stderr в отдельный файл.
- Условия, циклы, функции, обработка ошибок.
- **Отчёт:** матрица прав + скрипт аудита пользователей.

## Билет 5. «Процессы и сигналы»
- ВМ: гипервизор, ресурсы (CPU/RAM), снимок.
- Установка Linux Server, настройка.
- FHS: `/proc`, `/sys` — как ядро показывает процессы.
- Файлы: `find /proc -name status`, маски, `man 5 proc`.
- Пользователи: создать `runner`, выдать sudo на `systemctl`.
- Права: ограничить доступ к скриптам через chmod/chown/umask.
- Процессы: запустить `yes > /dev/null`, найти PID, `SIGSTOP`, `SIGCONT`, `SIGKILL`.
- Диагностика: `top`, `htop`, `nice`, `renice`, `ulimit`.
- Bash: скрипт-монитор с аргументами и кодами завершения.
- Потоки: `2>&1`, `tee`, конвейер с `grep` и `awk`.
- Цикл `while`, функция, `trap` для очистки.
- **Отчёт:** лог мониторинга + скрипт в `/root/reports/`.
